# 🛒 E-Commerce Product Page

A modern, interactive e-commerce product page built with **HTML5**, **CSS3**, and **JavaScript**.

## ✨ Features
- Product image gallery with thumbnail switcher
- Color selector
- Size selector (with out-of-stock states)
- Quantity adjuster
- Add to cart with live cart counter
- Wishlist toggle
- Product tabs (Description, Specifications, Reviews)
- Toast notifications
- Fully responsive layout

## 🛠️ Tech Stack
HTML5 · CSS3 · Vanilla JavaScript
